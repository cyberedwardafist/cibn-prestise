Email Pengirim (Resend)

Alamat ini dipakai sistem untuk mengirim kode OTP (pendaftaran & lupa kata sandi) dan pesan/notifikasi lain ke user & review.

Belum Diatur
API Key di bawah ini dipakai server untuk benar-benar mengirim email lewat Resend (kode OTP pendaftaran & lupa kata sandi, serta notifikasi pengingat kelas H-1 & saat kelas dimulai). Daftar gratis di resend.com → Dashboard → API Keys → Create API Key, lalu tempel di sini. Tidak perlu 2-Step Verification atau App Password Google sama sekali. Simpan lalu tekan "Tes Koneksi" untuk memastikan email percobaan benar-benar sampai.
Alamat yang akan tercantum sebagai pengirim OTP & pesan sistem lainnya. Tanpa domain terverifikasi di Resend, pakai onboarding@resend.dev bawaan.
Muncul sebagai nama pengirim di inbox penerima.
Dari resend.com → Dashboard → API Keys. Beda dari App Password Gmail — ini cukup 1 kode, tanpa akun Google sama sekali.

Google Meet — Jadwal

Dipakai untuk membuat tautan Google Meet otomatis pada fitur Jadwal di halaman User & Review.

Belum Terhubung
Isi Client ID & Client Secret dari Google Cloud Console (OAuth 2.0 Client, tipe "Web application"), tambahkan Redirect URI di sana, simpan pengaturan, lalu klik "Hubungkan Akun Google" untuk memberi izin akses Kalender. Begitu terhubung, sesi Jadwal yang masuk status "Berlangsung" otomatis dibuatkan room Google Meet asli & linknya dikirim ke akun tentor & murid yang bersangkutan.
Kalender Google tempat jadwal & link Meet akan dibuat.
